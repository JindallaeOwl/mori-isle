# Mori Isle

3D 스프라이트 적층(Sprite Stacking) 방식의 미니어처 디오라마 빌더입니다. 작은 섬에 오두막, 나무, 길, 소품을 놓아 꾸미는 웹 애플리케이션이에요.

전체 아트 방향, UX 규칙, 연출, 최적화 기준은 [3d.md](3d.md)에 정리되어 있습니다.

## 실행하기

[mori_isle.html](mori_isle.html)을 브라우저로 열면 바로 실행됩니다. three.js(unpkg)와 글꼴(jsDelivr)을 불러오기 때문에 **인터넷 연결이 필요합니다.**

개발할 때는 로컬 서버를 쓰는 편이 편합니다.

```powershell
python -m http.server 8765
```

그다음 `http://localhost:8765/mori_isle.html`을 엽니다. VS Code에서는 Live Server 확장을 써도 됩니다.

배치한 내용은 저장되지 않으며, 새로고침하면 처음 상태로 돌아갑니다.

### 시작 화면

불러오는 동안은 검은 화면이고, 준비가 끝나면 화면이 서서히 밝아지면서 섬이 조립됩니다. 순서는 암반 → 흙층 → 잔디와 언덕 → 연못 → 나무와 오두막 → 작은 소품 → 불빛 → UI이고, 약 3.4초 걸립니다. 섬 층과 오두막이 내려앉을 때는 크림색 충격 고리가 바닥에 퍼지고, 불이 켜질 때는 작은 픽셀 별이 반짝입니다. 조립 중에는 건너뛸 수 없고, 휠 확대 말고는 입력을 받지 않습니다. 섬 초기화의 "처음 섬으로"를 누르면 섬이 흔들리다 아래로 떨어진 뒤 같은 방식으로 다시 조립됩니다. three.js를 받지 못하면 검은 화면에 "다시 불러오기"가 뜹니다.

소리는 켜진 상태가 기본입니다. 다만 브라우저는 사용자가 클릭하거나 키를 누르기 전에는 소리를 막기 때문에, 첫 방문에서는 보통 첫 클릭이나 키 입력부터 소리가 납니다. 브라우저가 이미 소리를 허락한 경우에는 조립 소리도 처음부터 납니다.

### URL 옵션

주소 끝에 붙여 씁니다. 예: `mori_isle.html#fps=1&zoom=18`

| 옵션 | 효과 |
| --- | --- |
| `fps=1` | 왼쪽 아래에 프레임 수, 내부 해상도, 품질 배율, draw call 수 표시 |
| `hires=1` | 픽셀 렌더링을 끄고 원래 해상도로 그림 (비교용) |
| `noscale=1` | 자동 해상도 조절 끄기 |
| `zoom=N` | 시작 확대 정도 (16 ~ 62, 작을수록 확대, 기본 42.5) |
| `time=golden` / `time=night` | 그 시간대로 시작 |
| `elev=N` | 시작 상하 각도 (도 단위, 30 ~ 86, 기본 약 35) |
| `pan=x,z` | 섬의 그 지점을 보며 시작 (예: `pan=-1.6,-2.6`은 기본 섬의 오두막 굴뚝, 중심에서 6.5 이내) |
| `explode=1` | 분해 보기로 시작 |
| `noao=1` / `nodof=1` / `nobloom=1` | AO / 깊이 블러 / 블룸 끄기 (성능·화면 비교용) |
| `noopt=1` | 그림자를 매 프레임 다시 그림 (최적화 전후 비교용) |
| `intro=0` | 조립 연출 없이 바로 완성된 섬으로 시작 |
| `debug=1` | 자동 테스트용 읽기 전용 상태 훅 `window.__mori` 켜기. 조립 연출도 기본으로 꺼지며, `debug=1&intro=1`이면 켜짐 |
| `stack=1` | 가로등·벤치를 예전 적층 버전으로 보기 (조립 방식과 비교용) |

## 조작법

| 입력 | 동작 |
| --- | --- |
| 왼쪽 클릭 | 선택한 오브젝트 설치 (지우개 선택 시 삭제, 지형 도구는 그 칸을 한 단 올리거나 내림, 땅 칠하기는 누른 채 끌어서 칠함) |
| 오른쪽 클릭 | 삭제 |
| 오른쪽 드래그 | 좌우: 회전 / 위아래: 상하 각도 (아래로 끌면 위에서 내려다봄) |
| 휠 버튼 드래그 / `Shift` + 오른쪽 드래그 | 화면 이동 (잡은 땅이 커서를 따라옴) |
| 마우스 휠 / 터치패드 두 손가락 위아래 스크롤 | 커서 위치를 향해 확대·축소 |
| 터치패드 두 손가락 좌우 스와이프 | 회전 |
| 터치패드 핀치 | 확대·축소 |
| `←` `→` / `↑` `↓` | 회전 / 상하 각도 |
| `W` `A` `S` `D` | 화면 이동 |
| `F` | 기본 시점으로 되돌리기 (이동·확대도 초기화) |
| `1` ~ `6` | 카테고리 선택 (건물, 나무·식물, 길·담, 생활 소품, 자연 소품, 지형). 같은 키를 다시 누르면 그 안의 다음 오브젝트 |
| `X` | 지우개 |
| `R` | 오브젝트 방향 돌리기 |
| `E` | 디오라마 분해 보기 |
| `H` | 조작법 보기 |
| `Esc` | 감상 모드·열린 창 닫기 |

감상 모드와 분해 보기에서는 왼쪽 드래그로도 회전하고, 두 번 클릭하면 그 지점으로 확대, 다시 두 번 클릭하면 원래대로 돌아갑니다. 꾸미기 모드에서는 클릭이 설치이므로 두 번 클릭 확대는 쓰지 않습니다. 터치 화면에서는 두 손가락으로 확대·축소, 회전, 상하 각도를 바꿉니다.

상하 각도는 30°부터 거의 바로 위(86°)까지 움직입니다. 스프라이트 적층 방식은 옆이나 아래에서 보면 층이 갈라져 보여서, 수평 시선과 아래 시점은 막았습니다.

맨 오른쪽 '지형' 카테고리의 땅 올리기·내리기로 칸마다 높이를 0~3단까지 바꿀 수 있습니다. 비탈과 지층 벽은 저절로 생기고, 놓인 나무·소품은 땅을 따라 움직입니다. 연못 근처, 그리고 오두막·돌길·소품이 비탈에 걸리게 되는 칸은 바뀌지 않습니다(커서가 빨간색). 같은 카테고리의 잔디·모래·흙·돌바닥은 누른 채 끌면 ¼칸씩 땅을 칠합니다. 모래·흙·돌바닥에는 풀포기가 나지 않습니다. 잔디로 칠하면 처음 잔디로 돌아갑니다. 연못 안은 칠할 수 없습니다.

자연 소품의 '들꽃 씨앗'은 클릭하면 한 줌을 뿌려 여러 색의 작은 꽃이 땅에서 자라 오르고, 누른 채 끌면 지나간 자리에 계속 뿌립니다. 물·돌길·칠한 땅에는 나지 않고, 지우개로 몇 송이씩 지웁니다. ('들꽃'은 따로 놓는 꽃 무더기입니다.) "처음 섬으로"는 지형과 칠한 땅도 처음 모양으로 되돌리고, "모두 비우기"는 오브젝트만 지웁니다.

화면에는 글자 대신 아이콘만 둡니다. 아래쪽 카테고리 아이콘에 마우스를 올리면(터치 화면에서는 누르면) 그 위로 오브젝트들이 떠오르고, 하나를 고르면 그 카테고리 아이콘이 고른 오브젝트로 바뀝니다. 오른쪽 위 아이콘은 시간대(낮·노을·밤), 배경음, 분해 보기, 감상 모드, 섬 초기화, 조작법입니다. 한동안 아무것도 움직이지 않으면 UI가 옅어집니다. 글꼴은 [Galmuri](https://github.com/quiple/galmuri)(SIL Open Font License)를 씁니다.

## 소리

소리는 기본으로 켜져 있고(첫 클릭이나 키 입력부터 재생), 배경음 버튼으로 끌 수 있습니다. 바람, 풍경 소리, 모닥불 소리가 납니다.

- **섬 조립음:** 섬 층이 내려앉을 때 낮은 '쿵', 연못에 물이 찰 때 '퐁', 오브젝트마다 나무 '톡'(전체 순서를 따라 음이 계속 올라감), 불이 붙을 때 '화르륵'과 따뜻한 두 음, 초기화할 때 낮은 우르릉 소리.

- **설치음:** 밴드패스 필터를 거친 노이즈로 나무 '톡' 소리를 내고, 층이 올라갈수록 음이 높아집니다. 화면 왼쪽·오른쪽 위치에 따라 소리도 좌우로 나뉩니다.
- **모닥불:** 낮게 깔리는 우르릉 소리와 무작위 타닥 소리. 모닥불이 화면 중앙에 가깝고 확대할수록 커집니다.
- **잔향과 압축:** 코드로 만든 잔향을 살짝 섞어 공간감을 주고, 마지막에 컴프레서로 소리가 겹쳐도 찢어지지 않게 합니다.
- 탭을 가리면 소리를 멈춥니다.

배경음을 꺼도 설치음과 분해 보기 효과음은 작게 납니다.

그림과 소리 파일 없이 모델, 텍스처, 효과음을 코드로 만듭니다. 기술 스택은 Three.js 0.160과 Web Audio API입니다.

가로등·벤치 같은 구조물은 [Cinderwatch](https://github.com/kevintngo/cinderwatch)(MIT 라이선스, Copyright (c) 2026 kevintngo)의 도형 조립 방식과 재질·요철 셰이더를 옮겨 만들었습니다. 라이선스 전문은 `mori_isle.html`의 해당 코드 위에 있습니다.

## 렌더링 방식

1. **씬:** 화면보다 작은 해상도로, 밝은 빛이 1.0을 넘을 수 있게 HDR(half float)로 그리고 깊이도 함께 저장합니다. 화면 픽셀 2×2 이상이 씬 픽셀 하나가 되고, 내부 높이는 최대 600px입니다.
2. **대기:** 하늘을 합성하고, 깊이로 구석과 밑동을 어둡게 하는 AO를 넣고, 낮게 깔리는 안개를 근처 불빛 색으로 물들입니다.
3. **깊이 블러:** 카메라가 보는 지점에서 앞뒤로 멀어질수록 흐려지는 틸트 시프트입니다. 확대할수록 초점 범위가 좁아져 미니어처 접사처럼 보입니다.
4. **블룸:** 밝은 부분만 뽑아 1/2, 1/4 해상도에서 흐리게 해 더합니다. 밤에는 기준을 낮춰 불빛이 더 번집니다.
5. **합성:** 색수차, 색 보정, 톤매핑, 비네팅, 8×8 Bayer 디더링.
6. **업스케일:** 화면 크기로 키우면서 픽셀 경계만 살짝 부드럽게 처리하고, 필름 그레인을 더합니다.

- 카메라는 직교 카메라이고, 화면 픽셀 단위로 위치를 맞춰서 회전·확대 중에도 픽셀이 지글거리지 않습니다. 남는 1픽셀 미만의 차이는 6단계에서 보정합니다.
- 내부 해상도는 확대·축소와 상관없이 같습니다. 그래서 축소하면 도트처럼, 확대하면 미니어처처럼 매끈하고 세밀하게 보입니다.
- 2초마다 프레임 시간을 재서, 느리면 내부 해상도를 15%씩 낮추고(최저 55%) 여유가 생기면 다시 올립니다. 최저 해상도에서도 느리면 AO를 끄고 블러 반경을 절반으로 줄입니다.

### 최적화

화면 결과는 그대로 두고 일을 줄이는 방식입니다. 기본 섬 기준으로 프레임당 draw call이 228개에서 59개로 줄었습니다.

- **그림자 필요할 때만 갱신:** 주광은 움직이지 않으므로, 설치·삭제, 낙하 애니메이션, 분해 보기 전환 중에만 그림자 맵을 다시 그립니다.
- **오두막 메쉬 합치기:** 부품 96개를 6개로 합칩니다. 색, 거칠기, 금속감, 발광을 꼭짓점마다 넣어 재질 17종을 하나로 쓰기 때문에, 보이는 모습은 그대로입니다. 낙하 애니메이션이 끝난 뒤 합치고, 분해 보기는 덩어리 단위라 그대로 동작합니다.
- **조명 개수 고정:** 포인트 라이트 8개를 항상 켜 두고 안 쓰는 것은 밝기만 0으로 둡니다. 가로등·모닥불을 놓을 때 셰이더가 다시 컴파일되며 생기던 끊김을 없앱니다. 불빛 오브젝트가 8개보다 많으면 화면 중심에 가까운 8개가 켜지고, 화면을 옮기면 서서히 넘겨받습니다.
- **빈 인스턴스 건너뛰기, 변하지 않는 접지 그림자 갱신 생략.**
- **GPU 메모리 누수 수정:** 다시 만들 때마다 버려지던 오두막 지오메트리·재질을 해제합니다.

## 현재 상태

최근 작업:
- 시작 화면: 검은 화면에서 페이드인 → 섬이 아래층부터 타다닥 조립(충격 고리, 픽셀 먼지) → 불빛과 별 반짝임 → UI 등장, 섬 초기화 때 무너졌다 다시 조립
- 어둡고 차가운 밤 + 따뜻한 불빛, 노이즈 깜빡임, 일렁이는 모닥불 불꽃과 불티
- 화면 이동, 커서 위치로 확대, 두 번 클릭 확대
- 소리: 나무 설치음, 좌우 위치감, 잔향·압축, 모닥불 소리
- 카메라 상하 각도 조절, 터치패드 조작 개선, 렌더링 최적화
- 깊이 기반 틸트 시프트, 블룸, 화면 기반 AO, 불빛에 물드는 안개
- 픽셀 느낌 렌더링 (저해상도 + 또렷한 업스케일, 직교 카메라 1픽셀 정렬, 디더링, 필름 그레인, 자동 해상도 조절)
- 레고 조립식 '타다닥' 설치 애니메이션 (층별 낙하, 스쿼시 반동, 반짝임, 픽셀 먼지, 화면 흔들림, 피치 상승 효과음)

모든 작업은 실제 노트북 화면에서 움직임과 소리는 직접 확인이 필요합니다.

명세서와 비교해 남은 항목:

- [x] 카메라 상하 각도 조절 (30° ~ 86°)
- [ ] 후처리: 1픽셀 외곽선, 샤픈
- [x] 상단 조작 안내 배너 제거 (명세서의 미니멀 UI 규칙)
