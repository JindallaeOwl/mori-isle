# Mori Isle

3D 스프라이트 적층(Sprite Stacking) 방식의 미니어처 디오라마 빌더입니다. 작은 섬에 오두막, 나무, 길, 소품을 놓아 꾸미는 웹 애플리케이션이에요.

전체 아트 방향, UX 규칙, 연출, 최적화 기준은 [3d.md](3d.md)에 정리되어 있습니다.

## 실행하기

[mori_isle.html](mori_isle.html)을 브라우저로 열면 바로 실행됩니다. three.js(unpkg)와 글꼴(Google Fonts)을 불러오기 때문에 **인터넷 연결이 필요합니다.**

개발할 때는 로컬 서버를 쓰는 편이 편합니다.

```powershell
python -m http.server 8765
```

그다음 `http://localhost:8765/mori_isle.html`을 엽니다. VS Code에서는 Live Server 확장을 써도 됩니다.

배치한 내용은 저장되지 않으며, 새로고침하면 처음 상태로 돌아갑니다.

### URL 옵션

주소 끝에 붙여 씁니다. 예: `mori_isle.html#fps=1&zoom=18`

| 옵션 | 효과 |
| --- | --- |
| `fps=1` | 왼쪽 아래에 프레임 수, 내부 해상도, 품질 배율, draw call 수 표시 |
| `hires=1` | 픽셀 렌더링을 끄고 원래 해상도로 그림 (비교용) |
| `noscale=1` | 자동 해상도 조절 끄기 |
| `zoom=N` | 시작 확대 정도 (16 ~ 62, 작을수록 확대, 기본 42.5) |
| `time=golden` / `time=night` | 그 시간대로 시작 |
| `elev=N` | 시작 상하 각도 (도 단위, -50 ~ 86, 기본 약 35) |
| `explode=1` | 분해 보기로 시작 |
| `noao=1` / `nodof=1` / `nobloom=1` | AO / 깊이 블러 / 블룸 끄기 (성능·화면 비교용) |
| `noopt=1` | 그림자를 매 프레임 다시 그림 (최적화 전후 비교용) |

## 조작법

| 입력 | 동작 |
| --- | --- |
| 왼쪽 클릭 | 선택한 오브젝트 설치 (지우개 선택 시 삭제) |
| 오른쪽 클릭 | 삭제 |
| 오른쪽 또는 휠 버튼 드래그 | 좌우: 회전 / 위아래: 상하 각도 (아래로 끌면 위에서 내려다봄) |
| 마우스 휠 / 터치패드 두 손가락 위아래 스크롤 | 확대·축소 |
| 터치패드 두 손가락 좌우 스와이프 | 회전 |
| 터치패드 핀치 | 확대·축소 |
| `←` `→` / `↑` `↓` | 회전 / 상하 각도 |
| `F` | 기본 시점으로 되돌리기 |
| `1` ~ `9` | 도구 선택 (오두막, 침엽수, 활엽수, 길, 울타리, 모닥불, 가로등, 벤치, 바위) |
| `R` | 오브젝트 회전 |
| `E` | 디오라마 분해 보기 |
| `Esc` | 감상 모드 종료 |

감상 모드와 분해 보기에서는 왼쪽 드래그로도 회전합니다. 터치 화면에서는 두 손가락으로 확대·축소, 회전, 상하 각도를 바꿉니다.

상하 각도는 섬 아래(-50°, 지층과 밑면)부터 거의 바로 위(86°)까지 움직입니다.

하단 버튼으로 시간대(낮·노을·밤), 배경음, 감상 모드, 섬 초기화를 바꿀 수 있습니다.

그림과 소리 파일 없이 모델, 텍스처, 효과음을 코드로 만듭니다. 기술 스택은 Three.js 0.160과 Web Audio API입니다.

## 렌더링 방식

1. **씬:** 화면보다 작은 해상도로, 밝은 빛이 1.0을 넘을 수 있게 HDR(half float)로 그리고 깊이도 함께 저장합니다. 화면 픽셀 2×2 이상이 씬 픽셀 하나가 되고, 내부 높이는 최대 600px입니다.
2. **대기:** 하늘을 합성하고, 깊이로 구석과 밑동을 어둡게 하는 AO를 넣고, 낮게 깔리는 안개를 근처 불빛 색으로 물들입니다.
3. **깊이 블러:** 카메라가 보는 지점에서 앞뒤로 멀어질수록 흐려지는 틸트 시프트입니다. 확대할수록 초점 범위가 좁아져 미니어처 접사처럼 보입니다.
4. **블룸:** 밝은 부분만 뽑아 1/2, 1/4 해상도에서 흐리게 해 더합니다. 밤에는 기준을 낮춰 불빛이 더 번집니다.
5. **합성:** 색수차, 색 보정, 톤매핑, 비네팅, 8×8 Bayer 디더링.
6. **업스케일:** 화면 크기로 키우면서 픽셀 경계만 살짝 부드럽게 처리하고, 필름 그레인을 더합니다.

- 카메라는 직교 카메라이고, 화면 픽셀 단위로 위치를 맞춰서 회전·확대 중에도 픽셀이 지글거리지 않습니다. 남는 1픽셀 미만의 차이는 6단계에서 보정합니다.
- 내부 해상도는 확대·축소와 상관없이 같습니다. 그래서 축소하면 도트처럼, 확대하면 미니어처처럼 매끈하고 세밀하게 보입니다.
- 2초마다 프레임 시간을 재서, 느리면 내부 해상도를 15%씩 낮추고(최저 55%) 여유가 생기면 다시 올립니다. 최저 해상도에서도 느리면 AO를 끄고 블러 반경을 절반으로 줄입니다.

### 최적화

화면 결과는 그대로 두고 일을 줄이는 방식입니다. 기본 섬 기준으로 프레임당 draw call이 228개에서 80개로 줄었습니다.

- **그림자 필요할 때만 갱신:** 주광은 움직이지 않으므로, 설치·삭제, 낙하 애니메이션, 분해 보기 전환 중에만 그림자 맵을 다시 그립니다.
- **오두막 메쉬 합치기:** 부품 96개를 같은 재질끼리 합쳐 29개로 줄였습니다. 낙하 애니메이션이 끝난 뒤 합치고, 분해 보기는 덩어리 단위라 그대로 동작합니다.
- **조명 개수 고정:** 포인트 라이트 8개를 항상 켜 두고 안 쓰는 것은 밝기만 0으로 둡니다. 가로등·모닥불을 놓을 때 셰이더가 다시 컴파일되며 생기던 끊김을 없앱니다.
- **빈 인스턴스 건너뛰기, 변하지 않는 접지 그림자 갱신 생략.**
- **GPU 메모리 누수 수정:** 다시 만들 때마다 버려지던 오두막 지오메트리·재질을 해제합니다.

## 현재 상태

최근 작업:
- 카메라 상하 자유 시점, 터치패드 조작 개선, 렌더링 최적화
- 깊이 기반 틸트 시프트, 블룸, 화면 기반 AO, 불빛에 물드는 안개
- 픽셀 느낌 렌더링 (저해상도 + 또렷한 업스케일, 직교 카메라 1픽셀 정렬, 디더링, 필름 그레인, 자동 해상도 조절)
- 레고 조립식 '타다닥' 설치 애니메이션 (층별 낙하, 스쿼시 반동, 반짝임, 픽셀 먼지, 화면 흔들림, 피치 상승 효과음)

모든 작업은 실제 노트북 화면에서 움직임과 소리는 직접 확인이 필요합니다.
